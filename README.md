# GKPI Sidikalang Kota Church Website

An academic web development project focused on developing a church information website for GKPI Sidikalang Kota.

## Project Overview

The GKPI Sidikalang Kota Church Website was developed as an academic project to support the presentation of church-related information through a web-based platform. The project involved requirements gathering, system documentation, development, and manual software testing to validate implemented features against the defined requirements.

## Project Information

- **Project Type:** Academic Project
- **Project Period:** February 2024 – June 2024
- **Role:** Project Manager & Software Quality Assurance
- **Technology Stack:** PHP, Laravel, MySQL

## Roles & Responsibilities

### Project Management & Requirements Analysis
- Led requirements gathering to identify and document the system's functional needs.
- Prepared process flows and functional specifications as references for system development.
- Coordinated project activities to support alignment between requirements and implementation.

### Software Quality Assurance
- Performed manual testing to verify implemented features against functional requirements and expected system behavior.
- Documented testing findings and recurring defects to support issue identification and resolution.
- Reviewed system behavior to help ensure the implementation aligned with the documented specifications.

## Technology Stack

- **PHP** — Server-side programming language.
- **Laravel** — Web application framework.
- **MySQL** — Relational database management system.

## Key Learning Outcomes

- Requirements gathering and functional specification documentation.
- Project coordination and collaboration.
- Manual functional testing and requirement-based validation.
- Defect identification and test documentation.
- Understanding the relationship between system requirements, implementation, and software quality assurance.
